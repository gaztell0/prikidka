# Прикидка

Статический русскоязычный калькулятор: объём, сложность, риски → SP и плановые человеко-часы. Правило проекта: **1 SP = 8 человеко-часов**. Без серверной базы, аналитики, cookies и localStorage; без внешних ресурсов и зависимостей.

## Запуск

Node.js 18+: `npm run dev`, затем http://127.0.0.1:4173. Тесты: `npm test`. Файлы сайта находятся в корне репозитория; сборка не нужна.

## Модель v3

- Три оценки — целые 1–5 с пояснениями.
- База объёма: `[0.5, 1, 2, 4, 8]` SP.
- Множители сложности: `[1, 1.25, 1.5, 2, 3]`.
- Множители риска: `[1, 1.1, 1.25, 1.5, 2]`.
- Автоматические SP — произведение трёх коэффициентов, округлённое вверх до 0.1 SP; целочисленная арифметика защищает точные границы от ошибок floating point.
- Итог можно заменить вручную: 0.01–1000 SP, максимум два знака после запятой. Поддерживаются запятая и точка. Ручное значение заменяет итог целиком, дополнительные множители к нему не применяются. Изменение любого из трёх параметров возвращает автоматический расчёт.
- Часы строго равны итоговым SP × 8: 0.5 SP = 4 ч; 1.2 SP = 9.6 ч; 1.5 SP = 12 ч. Часы отображаются с точностью до сотых; дополнительных процентов нет.
- При SP ≥ 13 — рекомендация дробления; при рисках ≥ 4 — исследования.
- Нет кнопок копирования, рекламного блока, надписей о регистрации и LIVE.

Коэффициенты — собственная стартовая модель, которую следует согласовать на знакомых команде задачах. SP и часы здесь выражают одну оценку, а не два независимых прогноза. Человеко-часы не равны календарным срокам; сопоставляйте план с фактом.

## Совместимость ссылок

Ранее опубликованные ссылки `#m=2&v=3&c=2&r=2` сохраняют прежний результат (5 SP = 40 ч), старую базу объёма `[1,2,3,5,8]` и округление вверх по Фибоначчи. Смена параметра переводит интерфейс на v3. Новые параметры можно передать вручную через `#m=3&v=1&c=1&r=1&sp=1.2`; URL fragment не отправляется HTTP-серверу. Старые ссылки не меняют коэффициент 8 ч/SP.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в публичный репозиторий GitHub, ветка `main`.
2. Откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь успешной публикации. GitHub покажет ссылку на сайт в разделе Pages.

Файл `.nojekyll` отключает обработку Jekyll. Все ссылки и импорты относительные, поэтому калькулятор работает и по адресу проекта вида `/prikidka/`. Последующие изменения в `main` будут публиковаться автоматически.
