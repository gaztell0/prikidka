# Прикидка — калькулятор PERT-оценки

Одностраничный статический калькулятор трёхточечной оценки задачи: три сценария в часах, результат в часах и в SP. Без фреймворков, зависимостей, сборки и отдельных workflow.

Интерфейс переключается между русским и английским; выбор сохраняется в браузере.

Сайт: https://gaztell0.github.io/prikidka/

## Что считает

| Величина | Формула |
| --- | --- |
| Часы | `(O + 4M + P) / 6` |
| SP | `часы / 8` |

- `O` — оптимистичная оценка, `M` — наиболее вероятная, `P` — пессимистичная.
- Допустимый диапазон — от `0,01` до `100 000` ч, не больше двух знаков после запятой; принимаются запятая и точка.
- Обязателен порядок `O ≤ M ≤ P`, иначе поля подсвечиваются ошибкой.
- Пересчёт в SP — соглашение проекта, а не часть PERT. Границы `O…P` не являются доверительным интервалом.

## Локальный запуск

```bash
npm run dev
# http://127.0.0.1:4173
```

`server.js` — минимальный статический сервер с `cache-control: no-store`; он отдаёт только файлы сайта.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, inline-инициализация темы и языка до отрисовки |
| `style.css` | Светлая/тёмная тема, адаптивная вёрстка |
| `model.js` | Чистая модель: парсинг, валидация, PERT, состояние URL |
| `i18n.js` | Словари RU/EN и локализация чисел |
| `app.js` | DOM: ввод, ошибки, тема, подсказки, deep links, переключение языка |
| `server.js` | Локальный сервер для разработки |
| `package.json` | Только скрипт `npm run dev` |
| `.nojekyll` | Отключает Jekyll на GitHub Pages |

## Публикация

GitHub Pages публикует ветку `main` (корень репозитория) напрямую. Отдельного workflow, сборки и dev-сайта нет: любой push в `main` обновляет сайт.

В списке Actions может отображаться `pages-build-deployment` — это встроенный механизм GitHub Pages, а не workflow проекта.

## Кэш

При изменении `style.css`, `app.js`, `model.js` или `i18n.js` обновите `?v=<первые 12 символов sha256>` в `index.html` / `app.js`:

```bash
shasum -a 256 style.css | cut -c1-12
```

## Ограничения

- PERT-оценка — экспертный прогноз, а не измерение; уточняйте её по фактическим трудозатратам.
- Поддерживаются современные браузеры: используются ES-модули, `:has()` и `100svh`.
- Внешних зависимостей нет; `npm install` не требуется.
