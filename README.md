# Прикидка — калькулятор PERT-оценки

Одностраничный статический калькулятор трёхточечной оценки задачи: три сценария в часах, результат в часах и в SP. Без фреймворков, npm-зависимостей, сборки и отдельных workflow.

Интерфейс переключается между русским и английским; выбор сохраняется в браузере.

Сайт: https://gaztell0.github.io/prikidka/

## Что считает

| Величина | Формула |
| --- | --- |
| Часы | `(O + 4M + P) / 6` |
| SP | `часы / 8` |

- `O` — оптимистичная оценка, `M` — наиболее вероятная, `P` — пессимистичная.
- Допустимый диапазон — от `0,01` до `100 000` ч, не больше двух знаков после запятой; принимаются запятая и точка.
- Обязателен порядок `O ≤ M ≤ P`, иначе расчёт недоступен; после завершения ввода появляются пояснения.
- SP отображаются с округлением до десятых, без лишних нулей; при округлении добавляется `≈`. Положительные значения меньше `0,1 SP` показаны как `< 0,1 SP`. Расчёт часов и SP выполняется без промежуточного округления.
- Пересчёт в SP — соглашение проекта, а не часть PERT. Границы `O…P` не являются доверительным интервалом.

## Локальный запуск

```bash
npm run dev
# http://127.0.0.1:4173
```

`server.js` — минимальный статический сервер с `cache-control: no-store`; он отдаёт только файлы сайта.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, inline-инициализация темы и языка до отрисовки |
| `style.css` | Светлая/тёмная тема, адаптивная вёрстка |
| `model.js` | Чистая модель: парсинг, валидация, PERT, состояние URL |
| `i18n.js` | Словари RU/EN и локализация чисел |
| `analytics.js` | Базовый счетчик посещений, только на production-адресе |
| `app.js` | DOM: ввод, ошибки, тема, подсказки, deep links, переключение языка |
| `fonts/` | Локальный Inter Variable 4.1 и его лицензия SIL OFL 1.1 |
| `server.js` | Локальный сервер для разработки |
| `package.json` | Только скрипт `npm run dev` |
| `.nojekyll` | Отключает Jekyll на GitHub Pages |

## Публикация

GitHub Pages публикует ветку `main` (корень репозитория) напрямую. Отдельного workflow, сборки и dev-сайта нет: любой push в `main` обновляет сайт.

В списке Actions может отображаться `pages-build-deployment` — это встроенный механизм GitHub Pages, а не workflow проекта.

## Кэш

При изменении `style.css`, `app.js`, `model.js` или `i18n.js` обновите `?v=<первые 12 символов sha256>` в `index.html` / `app.js`:

```bash
shasum -a 256 style.css | cut -c1-12
```

## Ограничения

- PERT-оценка — экспертный прогноз, а не измерение; уточняйте её по фактическим трудозатратам.
- Поддерживаются современные браузеры: используются ES-модули, `:has()` и `100svh`.
- Внешних запросов за шрифтами нет: Inter загружается из `fonts/`. Его лицензия и уведомление об авторстве находятся в `fonts/LICENSE.txt`.
- `npm install` не требуется.

## Состояния интерфейса

- Пустые поля нейтральны; расчёт появляется автоматически после трёх корректных оценок.
- Формат проверяется после выхода из поля. При исправлении обратная связь обновляется сразу. Порядок оценок проверяется после завершения ввода всех трёх чисел.
- Пояснения об ошибках занимают ту же область, что и результат. Нажатие на пояснение переводит фокус в поле.
- На обычном масштабе ввод, ошибки и сброс сохраняют геометрию карточки. При увеличенном тексте содержимое может расширяться; раскрытие методики добавляет содержимое ниже формы.

## Статистика посещений

Яндекс Метрика: счетчик **114088227**. Отчеты доступны владельцу в [Метрике](https://metrika.yandex.ru/overview?id=114088227).

- Счетчик запускается только на `https://gaztell0.github.io/prikidka/` (также разрешены адрес без завершающего слеша и `index.html`). На localhost, других доменах, форках и dev-путях аналитика не запускается.
- Один просмотр на загрузку страницы; ввод оценок, тема и переключение языка не создают просмотров или пользовательских событий.
- Вебвизор, карты кликов, отслеживание ссылок и хеша, электронная коммерция, тег-менеджер и автоматические цели отключены. В настройках счетчика включен ограниченный режим обработки данных.
- В вызов `hit` передаются адрес страницы без query/hash и только origin источника перехода. Значения полей и результаты калькулятора не передаются через события, параметры или Вебвизор.
- Уведомление под калькулятором ведет к описанию собираемых Метрикой данных. Метрика использует cookies; счетчик считает браузеры, визиты и просмотры, а не гарантированное количество физических лиц. Блокировщики могут мешать сбору статистики.
- Аналитика подключена отдельным модулем и загружает библиотеку асинхронно: ее недоступность не блокирует расчет.
- При изменении `analytics.js` обновляйте его `?v=<первые 12 символов sha256>` в `index.html`.
